# Project documentation

The design spec and the implementation plans in `superpowers/` are written in
**French**. They are working documents kept for the record: they show what was
decided, why, and what the hardware turned out to do.

Everything a contributor needs is in English — the code, its comments, the
tests, `README.md`, and the commit messages, which started in French and
switched over with the rest of the project. `README.fr.md` is the French
translation of the root README.

| Document | Contents |
|---|---|
| `superpowers/specs/` | The design spec the whole project argues from |
| `superpowers/plans/` | One implementation plan per milestone, task by task — five for six milestones, the packaging one being small enough to go without |
