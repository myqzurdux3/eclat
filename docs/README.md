# Project documentation

The design spec and the implementation plans in `superpowers/` are written in
**French**, as are the commit messages. They are working documents kept for
the record: they show what was decided, why, and what the hardware turned out
to do.

Everything a contributor needs is in English — the code, its comments, the
tests, and the two READMEs at the root.

| Document | Contents |
|---|---|
| `superpowers/specs/` | The design spec the whole project argues from |
| `superpowers/plans/` | One implementation plan per milestone, task by task |
